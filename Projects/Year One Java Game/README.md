# 🕹️ 2D Java Game

This is a 2D game I developed at university as part of my coursework. It was built using Java and the **City** physics engine to simulate interactions within the game environment. The project involved designing game mechanics, rendering visuals, and handling basic physics for movement and collisions.

## 🚧 Disclaimer

⚠️ **Note:** This game no longer runs as originally intended because the **City** physics engine it relied on has since been deprecated and is no longer maintained. As a result, certain core features may not function properly out of the box.

## 🎮 Features

- 2D environment with player movement
- Basic game physics (gravity, collisions, etc.)
- Multiple game states (e.g. menu, gameplay, pause)
- Object-oriented design using Java
- Game loop with update and render cycles

## 🧰 Technologies Used

- Java
- City Physics Engine (now deprecated)
- Custom graphics rendering


## 🔧 Setup & Running (Legacy)

Because the game depends on the deprecated City physics engine, running it may require modifications.

1. Clone the repo
2. Ensure Java is installed (preferably JDK 8)
3. Import into your IDE (e.g. IntelliJ or Eclipse)
4. Run `Game.java`
